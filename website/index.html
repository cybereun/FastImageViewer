01이미지는 외부 서버로 전송되나요?

아니요. FastImage는 로컬 폴더의 이미지를 내 PC에서 처리합니다. 이미지 파일을 외부 서버에 업로드하지 않으며, 별도 계정도 필요하지 않습니다.

02Setup과 Portable은 어떻게 다른가요?

Setup은 Windows에 설치해 시작 메뉴와 바탕화면 바로가기를 만드는 방식입니다. Portable은 설치 과정 없이 EXE를 원하는 폴더에서 바로 실행하는 방식입니다.

03앱은 자동으로 업데이트되나요?

공개 GitHub Release를 기준으로 새 버전을 확인하고, 사용 중인 배포 방식에 맞는 업데이트 파일을 안내합니다. 업데이트가 필요한 경우 확인창에서 진행할 수 있습니다.

04어떤 이미지 형식을 지원하나요?

JPG/JPEG, PNG, GIF, BMP, WebP, SVG, ICO, TIFF, AVIF를 지원합니다. 일부 애니메이션 이미지는 편집·변환 시 첫 프레임 기준으로 처리될 수 있습니다.
